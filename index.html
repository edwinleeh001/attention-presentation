PART 01 / 5 MIN

Question & context

PART 011.5 MIN

Can attention replace recurrence?

The research question is about sequence transduction: read a sequence, then generate another.

  • Task: conditional sequence modeling, p(y | x) = ∏ p(yᵢ | y<ᵢ, x).
  • Claim: attention-based encoder–decoder representations can support strong translation without sequence-aligned recurrence or convolution.
  • Paper published in 2017; this handout follows the user-selected arXiv v7, revised in 2023.

SOURCE · §§1–3, pp.2–3

Speaker notes & audience prompt · 中文

先用翻译任务开场：输入句子已知，目标句子需要逐步生成。本文不是首次提出注意力，而是把注意力变成不同位置交换信息的主要机制。请指向概率分解：当前输出依赖源句和之前的输出。移除循环层，并不等于生成时不再自回归。讲解路线是整体结构、一次可计算的注意力，再到实验能支持什么结论。最后会区分 2017 年原始贡献与后续迁移学习应用。

提问：“没有循环层”是否表示能同时生成所有未知输出词？讲完掩码后再回答。
PART 011.5 MIN

Shorten the communication path

Parallel computation and long-range interaction are different design goals; the Transformer addresses both.

  • An RNN computes a hidden state from the preceding hidden state.
  • Convolutions can process positions in parallel, but distant positions require a growing receptive field.
  • Dense self-attention lets every position directly access all permitted positions within a layer.

SOURCE · §§1–2; Table 1, pp.2,6–7

Speaker notes & audience prompt · 中文

想象长句首尾两个词要交换信息。RNN 需要沿状态链传递；卷积能并行，但小卷积核不能一次覆盖全句。注意力允许位置之间建立依赖内容的直接连接。短路径属于结构性质，并不保证学到正确语言关系。每层的顺序操作数为常数，也不代表计算量不随长度变化，因为仍要计算每个查询—键对。到复杂度页时，要再次区分这两个概念。

请分别比较路径长度、顺序操作数和总计算量，不要用“更快”概括三者。
PART 012 MIN

What was actually new?

The contribution is a complete attention-based transduction architecture and its empirical validation.

  • Earlier work already used attention and self-attention.
  • The Transformer combines scaled dot products, learned attention heads, positional information and feed-forward blocks.
  • “All you need” does not mean the network contains only an attention operator.

SOURCE · §§2–3, pp.2–6

Speaker notes & audience prompt · 中文

不要说本文发明了注意力。背景章节已经引用翻译注意力及其他自注意力研究。主要变化是用注意力承担上下文交互，替代沿序列对齐的循环与卷积。周边结构仍不可少：词嵌入表示词元，位置编码提供顺序信息，前馈层变换特征，残差与归一化帮助优化。汇报应解释这些结构如何合作，而不是按标题字面理解。翻译质量、训练成本估算和结构消融检验的是不同问题，不能合并成“全面更优”。

在展示框架前，让听众说出两个必需的非注意力结构。

Inside the Transformer

PART 021 MIN

Read the full Transformer

The original model contains both an encoder and an autoregressive decoder.

Compare original Figure 1 ↗

  • Base configuration: 6 encoder layers, 6 decoder layers, d_model = 512, 8 heads.
  • Encoder memory supplies the keys and values of decoder cross-attention.
  • The original residual blocks are post-norm: LayerNorm(x + Sublayer(x)).

SOURCE · Figure 1; §§3.1–3.4, pp.3–5

Speaker notes & audience prompt · 中文

先沿源词元读到编码器记忆，再沿右移后的目标词元读完整个解码器。解码器多出的注意力使用自身状态作为查询，读取编码器记忆。强调两处 Softmax 的区别：头内部在允许的键位置上归一化；解码器顶部在词表上归一化以预测词元。六层重复不包括输入嵌入和输出分类器。这里明确画的是 2017 年后归一化结构，现代实现中的其他顺序或位置编码不能直接当作本文原设定。

指出唯一一个 Q 与 K、V 来自不同序列的注意力结构。
PART 021 MIN

Q asks, K matches, V carries content

Queries and keys determine weights; values determine what gets mixed.

Q

Query

n_q × d_k

K

Key

n_k × d_k

V

Value

n_k × d_v

  • Q ∈ ℝⁿq×dₖ, K ∈ ℝⁿk×dₖ, V ∈ ℝⁿk×dᵥ.
  • Scores have shape n_q × n_k; the output has shape n_q × d_v.
  • For self-attention, Q,K,V come from the same sequence through different learned projections.

SOURCE · Eq.1; §3.2, pp.4–5

Speaker notes & audience prompt · 中文

类比必须落到计算：一个查询与各键比较，为每个键位置产生分数；Softmax 将这一行分数变成权重；最后被加权的是值向量，不是键。键和值的数量必须一致，查询数量可以不同，所以同一算子可处理长度不同的源句和目标句。自注意力虽然共用输入序列，但 Q、K、V 的投影矩阵通常不同，并不意味着它们数值相同。

源句 5 个词元，解码器 3 个查询，交叉注意力权重是什么形状？答案：3 × 5。
PART 021.5 MIN

Scale, normalize, aggregate

Attention(Q,K,V) = softmax(QKᵀ / √d_k)V. Softmax acts along each query row.

A = softmax((QKᵀ / √d_k) + mask)
Z = AVNormalize per query row; mask=0 for allowed positions and −∞ for blocked positions.
  • Under independent zero-mean, unit-variance coordinates, Var(q·k) = d_k.
  • Dividing by √d_k controls score scale; it does not make Q and K unit vectors.
  • Mask forbidden scores before softmax; normalized weights then sum to one over allowed positions.

SOURCE · Eq.1 and footnote 4, p.4

Speaker notes & audience prompt · 中文

把公式分成四步：点积、除以键维度的平方根、逐行归一化、乘 V。在论文给出的简化独立方差假设下，点积方差随维度增长，缩放抵消这个效应。分数很大时 Softmax 会很尖锐，很多项的导数变小。这是动机，不是所有不缩放模型必失败的证明。缩放也不等于余弦相似度，向量长度依然影响结果。下一页使用明确给定的小矩阵，每个权重和输出都可独立复算。

为什么除以 √d_k 而不是 d_k？请从标准差解释。

PART 021.5 MIN

The same operator serves different roles because its inputs and allowed connections change.

Encoder self-attention

000000000

0−∞−∞00−∞000

Causal target positions

Rows: queries; columns: keys

Cross-attention

000000

Source memory keys / values

Rows: queries; columns: keys
  • Encoder self-attention: Q,K,V from source-side states; all source positions allowed.
  • Decoder self-attention: target-side Q,K,V with a causal mask.
  • Cross-attention: decoder Q, encoder-memory K,V; all non-padding source positions allowed.

SOURCE · §§3.1, 3.2.3, pp.3,5

Speaker notes & audience prompt · 中文

以三个目标词元为例，训练输入右移：起始符后接更早的真实目标词。因果掩码阻止当前位置读到更后面的目标输入。对角线可以保留，因为右移后当前位置装的是之前的目标词，而不是当前要预测的答案。训练时这些输入已知，可并行计算；生成时后续词未知，仍需逐步产生。源句已给定，交叉注意力不需对源位置施加因果限制。填充掩码是另一个问题，Padding 不是实际词元。

为什么允许对角线，却不允许未来目标位置？

Speaker notes & audience prompt · 中文

若对不含位置信息的内容向量重新排列，无掩码自注意力的输出也相应重排，它没有额外信息知道哪个词在前。位置编码通过加入依赖位置的向量消除这种歧义。正弦与余弦使用不同频率，覆盖多种尺度。公式可以在未见位置计算，但“有定义”不等于长上下文泛化可靠。表 3 的可学习位置与正弦位置开发集表现接近，因此不能说正弦位置是唯一选择，也不能说论文证明了无限长度外推。

区分“新位置上公式有定义”和“模型在那里表现良好”。
PART 021.5 MIN

Attention mixes positions; FFNs mix features

Residual paths and normalization connect these operations into a trainable deep network.

512 → Linear → 2048 → ReLU → Linear → 512
LayerNorm(x + Dropout(Sublayer(x)))
  • FFN(x)=max(0,xW₁+b₁)W₂+b₂; 512 → 2048 → 512 in the base model.
  • FFN weights are shared across positions within a layer, not across all layers.
  • Original order: sublayer → dropout → residual addition → layer normalization.

SOURCE · §§3.1,3.3,5.4, pp.3,5,8

Speaker notes & audience prompt · 中文

注意力从其他位置收集信息后，逐位置 FFN 对每个位置进行非线性特征变换。同一层各位置使用相同变换，不同层有不同参数。输出回到 512 维，才能与残差相加。原始结构先对各子层输出做 Dropout，再加残差，最后归一化。残差不是另一个注意力权重，而是独立的恒等路径。讲清这些顺序，可以避免把现代前归一化变体悄悄替换成论文结构。

单独的 FFN 能混合不同词元信息吗？不能，它逐位置独立作用。
PART 021 MIN

Training is part of the method

The architecture was paired with a specific optimization and regularization recipe.

lr = d_model−0.5 min(step−0.5, step × 4000−1.5)Original Eq.3; positive step numbers only.
  • Adam: β₁=.9, β₂=.98, ε=10⁻⁹; warmup for 4,000 steps, then inverse-square-root decay.
  • Base: dropout .1, label smoothing .1, 100K steps; big: 300K steps.
  • Training targets are known; generation uses beam search with predicted prefixes.

SOURCE · §§5.2–5.4,6.1–6.2, pp.7–9

Speaker notes & audience prompt · 中文

学习率先线性增大再衰减，并非恒定学习率的 Adam。正则化包括 Dropout 与标签平滑。论文指出，平滑可能让困惑度变差，却改善 BLEU，说明概率指标和任务质量不完全一致。基础与大模型同时改变规模和训练时长，其分数差不能单独归因于头数。最终翻译结果还包含检查点平均与束搜索，后面的开发集消融却没有检查点平均，要分清评估协议。

更低困惑度是否必然带来更高 BLEU？用标签平滑作为反例。

What the paper does not establish

A strong contribution is more credible when its evidence boundaries are explicit.

  • Attention visualizations suggest patterns; they do not prove causal explanations.
  • Machine translation and parsing results do not establish universal reasoning or few-shot ability.
  • Historical cost estimates, limited task coverage and absent multi-seed intervals constrain conclusions.

Q01Architecture / Original paperWhat are the two main modules of a Transformer?+

Transformer主要由哪两大核心模块构成？

The original model has an encoder that represents the source sequence and a decoder that predicts target tokens from those representations and the target prefix. At the sublayer level, the key building blocks are multi-head attention and a position-wise feed-forward network; each original decoder layer also has cross-attention.

Watch out

Distinguish the whole architecture from its sublayers. Encoder-only and decoder-only variants also exist.

Q02Architecture / Original paperWhat do Q, K and V mean in self-attention?+

自注意力机制里的 Q、K、V 分别是什么？

Queries describe what each position seeks; keys determine matching scores; values carry the information to aggregate. In self-attention, all three come from the same sequence representation X through different learned projections. Each query scores allowed keys, softmax normalizes the scores, and the resulting weights combine the values.

Q=XWQ, K=XWK, V=XWV; Attention(Q,K,V)=softmax(QKᵀ/√dₖ + M)V
Watch out

Q, K and V are learned representations, not three fixed words. Cross-attention uses different sequences for Q and K/V.

Q03Architecture / Original paperWhat is the main advantage of multi-head attention?+

多头注意力的核心优势在哪？

Different heads attend in different learned representation subspaces. Their outputs are concatenated and projected back to the model width, allowing a token to combine several relationships instead of relying on one weighted average. With fixed total width, each head is typically narrower.

Watch out

Heads need not have neatly interpretable roles, and adding heads does not guarantee improvement.

Q04Architecture / Paper + practiceWhy do we need positional information, and what forms can it take?+

Q05Architecture / Original paperHow do the original encoder and decoder differ structurally?+

Encoder和Decoder结构上最本质的区别是什么？

The original encoder uses bidirectional self-attention over valid source tokens. The decoder uses causal self-attention over the target prefix, then encoder–decoder cross-attention to the source representations, followed by a feed-forward network. It differs both in visibility and in its extra cross-attention sublayer.

Watch out

Cross-attention is part of the original decoder, but not required in every decoder-only language model.

Residual connections preserve an identity path and let a sublayer learn a correction, improving gradient propagation. Removing either often makes deep optimization harder or less stable, but the outcome depends on the setup.

Q07Architecture / Original paperWhere does a Transformer improve on an RNN for long sequences?+

处理长序列时，Transformer比RNN强在哪？

Self-attention provides direct interactions between visible positions, shortening long-range paths. Training can process positions in parallel when inputs and target prefixes are known, while an RNN has sequential recurrence. However, dense attention has quadratic score-matrix size in sequence length, and autoregressive decoding remains sequential.

Dense attention scores: n × n per head; pairwise attention work: O(n²d)
Watch out

Shorter dependency paths do not imply lower memory use or faster execution at every sequence length.

Q08Components / Original paperWhat does the feed-forward network do in a Transformer?+

前馈网络在Transformer里承担什么角色？

Attention exchanges information across tokens; the FFN nonlinearly transforms features within each token. The original base model uses two linear maps with ReLU, expanding from 512 to 2048 dimensions and projecting back to 512. Positions share FFN parameters within a layer, while different layers normally have different parameters.

FFN(x)=max(0,xW₁+b₁)W₂+b₂
Watch out

Position-wise does not mean separate weights for every position. The FFN itself does not mix tokens.

Q09Components / Original paperWhat are the two common attention masks, and what do they do?+

注意力掩码主要有哪两种？各自作用是什么？

A padding mask prevents attention to artificial PAD keys. A causal mask prevents position i from attending to future positions j>i. Conceptually, blocked scores receive negative infinity before softmax, giving them zero probability. Both masks can be combined; padded query outputs and loss positions need separate handling.

Mᵢⱼ=0 when allowed, −∞ when blocked
Watch out

Boolean mask conventions differ across APIs. Avoid unintentionally masking every key in a row.

Q10Components / Paper + practiceHow should embedding dimensionality be chosen?+

词嵌入维度一般怎么定？有经验参考吗？

Embedding width trades capacity against compute and memory; vocabulary size alone does not determine it. The original base and big models use widths of 512 and 1024. Q12Components / Original paperHow does masking work during decoder training, and why hide future tokens?+

Decoder训练阶段的“掩码”具体怎么工作？为什么不能看后面的词？

Shift targets right: inputs [BOS, y₁, y₂] predict [y₁, y₂, y₃]. At each position, causal attention allows the current and earlier inputs but blocks future ones. This prevents copying the answer and matches the information available at inference, while still enabling parallel training. Masking alone does not replace correct target shifting.

Watch out

The diagonal is normally allowed because inputs are shifted. This differs from BERT-style masked-token prediction.

Q13Components / Later extensionWhat is the idea behind pretraining, and how does it differ from training from scratch?+

Pretraining learns reusable representations or generation skills from broad data. A downstream task can then adapt those parameters with less task-specific data or use prompting. Q17Core concepts / Later extensionWhat is overfitting, and how can we detect it?+

什么是过拟合？实际中怎么判断？

Overfitting occurs when a model adapts too closely to training examples, including noise, and generalizes poorly. Q23Training & evaluation / Later extensionHow does data-parallel training work, and how are gradients synchronized?+

Each device holds a model replica and computes gradients on a different data shard. All-reduce aggregates gradients, usually by averaging; replicas then apply matching optimizer updates. Data sharding and update steps must align. Gradient accumulation can reduce synchronization frequency and increase effective batch size; unequal sample or token counts require correct weighting and loss normalization.

Smaller batches usually produce noisier gradients and may underutilize hardware. Larger batches use more memory and yield fewer updates for a fixed token budget, often requiring learning-rate and warmup changes. Choose a workable microbatch, use accumulation to set global batch size, and evaluate both validation behavior and throughput.

Neither larger nor smaller batches universally generalize better. For language models, also report effective tokens per update.

Q27Training & evaluation / Paper + practiceWhich metrics evaluate generation quality, and what does each emphasize?+

评估生成质量的常用指标有哪些？各自侧重什么？

For text, BLEU emphasizes reference n-gram precision with a brevity penalty; ROUGE commonly measures lexical coverage in summaries; BERTScore measures contextual semantic similarity. Q28Training & evaluation / Paper + practiceWhat does perplexity measure? Does it necessarily track generation quality?+

困惑度反映的是模型哪方面能力？和生成质量一定正相关吗？

Perplexity is the exponential of average token negative log-likelihood. It measures probability assigned to held-out text; lower is generally better under matched conditions. It does not directly assess generated factuality, usefulness or decoding outcomes. Values across different tokenizers, datasets or context windows are not directly comparable; standard perplexity is primarily for autoregressive models.

PPL = exp[−(1/T) Σₜ log pθ(xₜ | x<t)] (natural logarithm)
Watch out

There is no necessary monotonic relation to generation quality. The paper reports worse perplexity but better accuracy and BLEU with label smoothing.

Q29Applications & optimization / Paper + practiceHow do greedy decoding and beam search differ, and when are they useful?+

贪心解码和集束搜索的核心区别是什么？适用场景？

Greedy decoding keeps the highest-probability next token at each step. Beam search maintains B candidate prefixes and ranks expansions by cumulative log-probability, often with length penalties. It may help constrained generation such as translation, while sampling is often useful for open-ended diversity. Select decoding settings using task-specific evaluation.

Watch out

Beam search is approximate and does not guarantee the best sequence or the best answer for people. Larger beams are not always better.

Q30Applications & optimization / Later extensionHow does temperature affect generation? What about zero or very high values?+

温度参数怎么影响生成结果？设为0或很大分别会怎样？

For sampling, divide logits by positive temperature T before softmax. T<1 sharpens the distribution; T>1 flattens it. As T approaches zero, mass concentrates on maximal logits; very large T approaches uniformity over finite allowed logits before other filters. An API setting of zero is commonly a special greedy mode, not literal division by zero.

pᵢ(T)=exp(zᵢ/T) / Σⱼ exp(zⱼ/T), T>0
Watch out

Positive temperature preserves argmax ordering for fixed candidates, so ordinary greedy selection is unchanged. Low temperature does not guarantee truth.

Q31Applications & optimization / Later extensionWhy cap generation length, and what can happen without a limit?+

推理时为什么要限制最大生成长度？不限制会有什么后果？

A length limit bounds time and resource use. A model may not emit EOS promptly and can repeat or continue generating, increasing latency, cost and KV-cache memory or reaching the context limit. Distinguish maximum new tokens from total input-plus-output length, combine limits with stop conditions, and leave enough room for the task.

Watch out

A cap is a safeguard, not a quality guarantee. Short caps can truncate answers; distinguish length stops from normal completion.

Q32Applications & optimization / Later extensionWhat are common fine-tuning methods, and how do LoRA and adapters compare?+

大模型微调的主流方法有哪些？LoRA、Adapter各有什么特点？

Options include full fine-tuning, updating selected layers or task heads, and parameter-efficient methods such as LoRA, adapters and prompt/prefix tuning. LoRA freezes base weights and learns a low-rank update BA, which can often be merged for inference. Adapters insert small trainable bottleneck modules, enabling task switching but typically adding forward operations. Both reduce trainable parameters and optimizer state.

W′=W+BA; B∈ℝ^(d_out×r), A∈ℝ^(r×d_in); trainable parameters=r(d_in+d_out)
Watch out

PEFT still runs the backbone and stores needed activations. LoRA rank, target layers and data affect quality; parity with full fine-tuning is not guaranteed.

Questions and discussion

01Did this paper invent attention?

No. Its contribution is the Transformer transduction architecture; the paper itself reviews earlier attention and self-attention systems.

SOURCE · §2, p.2
02Why divide by the square root of key dimension?

Under the stated independence and unit-variance assumptions, dot-product variance is d_k. Scaling controls its standard deviation and reduces extreme softmax saturation.

SOURCE · §3.2.1, p.4
03Are attention weights probabilities of the next word?

No. They normalize over key positions. The separate decoder output softmax normalizes over vocabulary items.

SOURCE · §§3.2,3.4, pp.4–5
04Are Q, K and V identical in self-attention?

They share an input sequence, but normally use distinct learned projections. Their values need not be identical.

SOURCE · §3.2.2, p.5
05Why use multiple heads rather than one wide head?

Different projections permit different mixtures in distinct subspaces, followed by concatenation and an output projection. Table 3 supports multiple heads in this setting, not an unlimited benefit from adding heads.

SOURCE · Table 3(A), p.9
06What changes between self- and cross-attention?

The source of Q versus K,V. Decoder cross-attention uses decoder queries and encoder-memory keys and values. The same matrix operator applies.

SOURCE · §3.2.3, p.5
07Why are target inputs shifted right?

Together with the causal mask, shifting prevents a position from reading the very target it must predict. The allowed diagonal contains the preceding target token.

SOURCE · §3.1, p.3
08How can training be parallel but inference sequential?

Teacher-forced target prefixes are known during training. During generation, each next token depends on an earlier token that must first be produced.

SOURCE · §§3,3.1, pp.2–3
09Why are positional encodings necessary?

Unmasked self-attention without position signals is permutation-equivariant. Added position vectors expose order; sinusoidal encoding is one choice, not a uniqueness result.

SOURCE · §3.5, p.6; derivation in guide
10Is the original Transformer pre-norm?

No. The paper uses LayerNorm(x + Sublayer(x)), with dropout on the sublayer output during training. Modern variants may differ.

SOURCE · §§3.1,5.4, pp.3,8
11Does O(1) path length imply constant runtime?

No. Dense attention still computes n² interactions, plus projection and feed-forward work. Path length, work and wall-clock latency are distinct.

SOURCE · Table 1, pp.6–7

The selected v7 text is internally inconsistent: §6.1 prose says 41.0, while the abstract and Table 2 say 41.8. We use the table value and disclose the discrepancy; the source does not resolve it.

SOURCE · pp.1,8

No. 25.8 is a Table 3 dev score without checkpoint averaging; 28.4 is a Table 2 test score. Use matching splits and evaluation settings.

14Do attention maps explain model decisions?

They visualize a computation, but causal claims require additional evidence. The toy maps here are computed from declared synthetic matrices, not learned linguistic explanations.

15Does parsing prove zero-shot transfer?

No. Separate parsing models were trained. This supports architectural reuse, not frozen-weight zero-shot transfer from translation.

Match data, tokenization, parameter count, training budget and decoding. Run multiple seeds; measure BLEU, runtime and memory across lengths, then ablate heads and positional information separately. This is a proposed study, not a reported result.

With Q,K and the mask fixed, weights stay unchanged, but the weighted output changes. In an entire trained model, shared upstream parameters can couple these quantities.
